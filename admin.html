還沒連接 Firebase

請先把 Firebase 的設定貼進 js/firebase-config.js，再重新整理這個頁面。步驟寫在 README.md。

進入後台

只有群主能進入後台。

這個帳號沒有後台權限

目前登入的帳號是 。請登出後，改用群主的帳號登入。

如果這就是群主的帳號，請檢查 firestore.rules 裡的 UID 是否與 Firebase 控制台 Authentication → Users 裡該帳號的「使用者 UID」完全一致，而且規則已經發布。

新增待辦與回覆留言時會附上這個名字，只記在這台瀏覽器。不填就署名「群主」。

開啟前台

新增公告

可以換行；貼上以 http:// 或 https:// 開頭的網址，前台會自動變成連結。

批次匯入公告（上傳 JSON 檔）

一次上傳多則公告。檔案格式見 README；也可以把文字貼給 Claude，請它轉成這種 JSON 檔。公告依檔案裡的順序編號，最後一則的編號最大，會顯示在最上面。

      所有公告

        新增待辦事項

        待辦事項只有登入後台的人看得到，前台讀者看不到。

        待辦清單

          輪播設定

          一般圖片停留這麼久就換下一張；單張可以另外設定秒數。GIF 與影片不看這個數字：播完後再等 1 秒才換下一張。

          新增圖片或影片

          把圖片、GIF、MP4 檔案上傳到 GitHub 專案的 media 資料夾，這裡填 media/檔名.jpg。也可以填 https:// 開頭的網址。前台沒有任何一張在顯示時，整個圖片牆不會出現。

          給看不到圖的人（螢幕閱讀器）聽的描述，不會顯示在畫面上；在這個列表裡會當成標題。

          只對圖片與 GIF 有效；GIF 留空時是播完一輪再等 1 秒。影片一律播完。

          以你這台電腦的時區為準。時間一到，前台就不再播放這一張（正開著網頁的訪客也會即時消失）。資料還留在這裡，可以改時間延長，或按列表上方的「清除已到期」刪掉。
