          圖片牆內容

            從手機或電腦上傳檔案的設定（GitHub）

            要從手機或電腦直接上傳圖片、GIF、MP4，需要先給這個後台一組「只能寫入這個專案」的 GitHub 權杖（Token）。檔案會存進專案的 media 資料夾，費用是零，但網站重新發布要等一兩分鐘。只在第一次或權杖過期時需要設定；圖片牆與「網站設定」裡的網站背景共用這一份設定。

            1. 登入 GitHub → 右上角頭像 → Settings → 左下 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
            2. Repository access 選 Only select repositories，只選這個網站的專案。
            3. Permissions → Repository permissions → Contents 設成 Read and write，其他都不要開。
            4. 按 Generate token，複製那串以 github_pat_ 開頭的文字，貼到下面。

            只有當 GitHub Pages 發布的不是預設分支時才需要填。

            權杖等同密碼：拿到它的人可以修改這個專案裡的任何檔案（不只是 media 資料夾），請不要貼給別人，也不要寫進網站的檔案裡。勾「記住」時，權杖會存在這台手機或電腦的瀏覽器裡，而且同一個 GitHub 帳號底下的其他 GitHub Pages 網站也讀得到，請只在自己的手機或電腦上勾；沒勾時只留在這個分頁，登出或關掉分頁就消失。

            新增圖片或影片

            從手機或電腦上傳圖片、GIF 或 MP4。MP4 本身有聲音的話，放在圖片牆上也會有聲音。前台沒有任何一張在顯示時，整個圖片牆不會出現。

            給看不到圖的人（螢幕閱讀器）聽的描述，不會顯示在畫面上；在上面的列表裡會當成標題。

            留空：圖片停留輸入框裡顯示的預設秒數，GIF 與影片播完一輪後再等 1 秒。填了秒數：圖片與 GIF 就停留這麼久；影片一律播完。

            以你目前使用的裝置（手機或電腦）的時區為準。時間一到，前台就不再播放這一張（正開著網頁的訪客也會即時消失）。資料還留在這裡，可以改時間延長，或按列表上方的「清除已到期」刪掉。

            網站背景

            從手機或電腦上傳圖片、GIF 或 MP4，當作前台整個網頁的背景，可以調成半透明。公告、圖片牆等內容區塊維持原本的樣子，只有它們周圍露出背景。MP4 當背景時固定靜音、重複播放，建議用幾 MB 以內的短片。

            標語與歡迎文字顯示在網頁最上方的跑馬燈；服務窗口、辦事須知、辦公時間與連結、頁尾文字顯示在網頁最下方的頁尾。

            顯示在頁首左上角和瀏覽器分頁標題；頁尾文字留空時，頁尾也會顯示它。

            一行即可，會排在歡迎文字前面，一起在跑馬燈裡捲動。

            顯示在跑馬燈。每一行是一段，段與段之間會留一段空白。訪客把滑鼠移上去或點一下可以暫停。
